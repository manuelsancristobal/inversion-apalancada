## [0.1.0] - 2026-04-26

### Añadido
- Inicio del proyecto y estandarización para el portafolio.
- Motor de simulación de Monte Carlo basado en Movimiento Browniano Geométrico (GBM).
- Cálculo de métricas de riesgo: probabilidad de ruina, volatility drag, Sharpe Ratio y Max Drawdown.
- Interfaz web para visualización de curvas de capital y distribuciones de resultados.
- Configuración de CI/CD con GitHub Actions y pre-commit hooks.
